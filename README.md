# Fala! 🇧🇷

Application web pour apprendre le portugais brésilien (interface en français) : parcours par thèmes, fiches intelligentes à répétition espacée, compréhension orale, prononciation, argot, discussions interactives, grammaire et conjugaison.

La progression est enregistrée localement dans le navigateur (aucun compte, aucun serveur).

## Lancer en local

```bash
npm install
npm run dev
```

## Publication

Chaque envoi sur la branche `main` publie automatiquement l'app sur GitHub Pages (voir `.github/workflows/deploy.yml`).
